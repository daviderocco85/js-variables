# JS-VARIABLES

Getting started with JavaScript variables

# Target 

Based on the provided material, the required JavaScript exercises were implemented using arithmetic operators and string concatenation through fundamental built‑in methods. The resulting outputs were validated using DevTools and console.log for runtime inspection.

# Exercises solutions

The exercise solutions are located in the respective script.js files within the following directories:

1. [01-numbers](01-numbers/script.js)
2. [02-strings](02-strings/script.js)
3. [03-strings-bonus](03-strings-bonus/script.js)

# Execution instructions

Download the ZIP archive of the entire project from the Code button, launch any index.html file within the exercise directories in a web browser and inspect the execution output via DevTools, using the Console panel for runtime logging.
